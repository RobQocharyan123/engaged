# Invitation background gallery

The public invitation automatically discovers supported image files in this folder and plays them in filename order.

- Keep `01-couple-upscaled.png` as the first image.
- Add the next photos as `02-...` and `03-...`.
- Supported formats: AVIF, GIF, JPEG, PNG, and WebP.
- Portrait images work best because the invitation is designed mobile-first.
